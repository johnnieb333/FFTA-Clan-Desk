# FFTA Clan Desk v0.1.0-beta — Windows x86_64

An independently maintained fork of Jorge262007/FFTARecomp, built on JRickey/gba-recomp, with a Clan Desk menu and integrated editor tools.

## Highlights

- Character roster with ROM-decoded job sprites.
- Staged stat/level, job, ability, inventory and clan-funds editing with confirmation and full-state Undo.
- 30 manual states and 10 rotating timed autosaves with previews and Undo Load.
- Adjustable autosave timing, visible stat-limit modes, hold-to-repeat and x1/x2/x5 unrestricted stat steps.
- Targeted dialogue, law-panel and mission-result display fixes.

Tested development platform: Windows x86_64, European FFTA ROM. Other regions/platforms are not claimed as tested for these additions. Players supply their own ROM; none is included.

Extract the complete Windows ZIP and run FFTA-Clan-Desk.exe. The launcher asks for a supported ROM if necessary. Esc opens the menu.

Original save-directory names remain for compatibility. Manual snapshots, timed history and the original QuickSave are separate. Game-possible limits are per-stat recruit/growth bounds, not a full-build legality checker. Some game displays refresh on a screen change.

Thanks to Jorge.R, JRickey, all upstream and dependency contributors, and everyone testing this fork. Licence notices and matching TinyCC source accompany the distribution.
